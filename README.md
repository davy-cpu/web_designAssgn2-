# Hot Pot - Web Design Platform

## Project Title
**‘Hot Pot’ Web Design Platform** - A hybrid, next-generation website builder for restaurants

## Project Overview
Hot Pot is a dual-sided website builder platform that bridges the gap between visual creativity and restaurant operations.

In the current web development landscape, restaurants face a critical dilemma: they must either choose restrictive, template-boxed platforms that hurt their unique brand identity, or hire expensive development agencies to build bespoke sites.

At the same time, young freelance designers want to sell premium, high-value websites to local hospitality clients but are limited by builders that lack deep, restaurant-specific backend features (like POS syncing and live ticketing).

**Hot Pot solves this by offering absolute canvas freedom for creators alongside turn-key operational infrastructure for restaurant operators.**

## Problem Statement
Existing website builders force an unacceptable compromise between visual form and operational function:

**For Restaurant Owners:**
- Traditional flexible builders (like Webflow) have a steep learning curve
- They lack built-in, commission-free ordering systems and real-time menu management
- Forcing reliance on expensive third-party plugins

**For Young Designers:**
- Dedicated restaurant site builders (like BentoBox) are visually rigid
- They restrict designers to boring, cookie-cutter layouts that fail to showcase creative talent
- They fail to command premium design fees

## Proposed Solution
An intuitive, dual-interface website builder platform featuring:

1.  **Visual Studio Mode** for designers
        - Craft bespoke, micro-animated, pixel-perfect frontend layouts
        - Total canvas freedom, grid-breaking layouts
        - Interactive hover states and responsive breakpoint controls
        - Clean code production

2.  **Operations Dashboard** for restaurant owners
        - Update live text menus
        - Alter operational hours
        - Fulfill direct online deliveries seamlessly
        - Mobile-first tools for fast, on-the-fly changes during a shift

These layouts automatically connect to specialized, structured backend modules.

## Target Users

### Primary User Group A: Independent Restaurant Owners, General Managers, and Hospitality Operators
- **Core Drivers:** Maximizing table occupancy, accelerating direct online ordering revenue, and lowering third-party commission overheads
- **Tech Literacy:** Medium to Low. Require mobile-first tools to make fast, on-the-fly text changes during a hectic shift

### Primary User Group B: Junior Web Designers, Freelance Creatives, and Agency Design Interns
- **Core Drivers:** Building a visually stunning design portfolio, learning modern web layout systems, and speeding up client project deliveries
- **Tech Literacy:** High. Expect advanced layout engines, clean code production, and responsive design breakpoint controls

## User Needs

1.  **The Accessibility Need (HTML Menus):**
    Real-time text-rendering engines to replace static PDF menus. This satisfies search engine crawlers for Local SEO and ensures mobile readability.

2.  **The Component Need (Design Tokens):**
    A structured system where designers can Lock global styles (colors, layout rules) while leaving specific text blocks unlocked so restaurant staff can safely edit them.

3.  **The POS Integration Need:**
    Direct data pipelines connecting frontend reservation forms with core restaurant hardware (e.g., Toast, Clover, OpenTable).

## Key Features

### For Designers (Visual Studio Mode)
- Drag-and-drop canvas with absolute positioning
- Design Tokens - Global styles for colors, fonts, layout rules
- Micro-animations and hover states
- Responsive breakpoint controls (Desktop / Tablet / Mobile)
- Client-handoff mode - Hide core design settings from owners
- Portfolio-ready export

### For Restaurant Owners (Operations Dashboard)
- Live text menu editor (HTML, not PDF)
- Daily specials editor
- Operational hours manager
- Commission-free direct online ordering
- Reservation management
- POS Sync - Toast, Clover, OpenTable
- Mobile dashboard
